**Files to create:**

```ts
// Generates wa.me deep links with pre-filled messages.
// WhatsApp requires E.164 phone numbers with the + stripped.

export function buildWhatsAppLink(e164Phone: string, message: string): string {
  const phone = e164Phone.replace(/^\+/, '');
  const encodedMessage = encodeURIComponent(message);
  return `https://wa.me/${phone}?text=${encodedMessage}`;
}

export function buildProviderToRequesterMessage(serviceType: string): string {
  return `Hi, I saw your request for ${serviceType} on Djema and I can help! Can we talk?`;
}

export function buildRequesterToProviderMessage(
  providerName: string,
  serviceType: string
): string {
  return `Hi ${providerName}, I found you on Djema. I need help with ${serviceType}. Are you available?`;
}
```

**src/utils/session.ts content:**
```ts
const SESSION_TOKEN_KEY = 'djema_session_token';

export function getOrCreateSessionToken(): string {
  const existing = localStorage.getItem(SESSION_TOKEN_KEY);
  if (existing) return existing;

  const token = crypto.randomUUID();
  localStorage.setItem(SESSION_TOKEN_KEY, token);
  return token;
}

export function clearSessionToken(): void {
  localStorage.removeItem(SESSION_TOKEN_KEY);
}
```

**src/utils/validation.ts content:**

```ts
import { z } from 'zod';

  .string()
  .regex(/^\+[1-9]\d{7,14}$/, 'Enter a valid phone number starting with + (e.g. +256700123456)');

export const emailSchema = z.string().email('Enter a valid email address');

export const serviceRequestSchema = z.object({
  serviceType: z.string().min(1, 'Select a service type'),
  description: z
    .string()
    .min(10, 'Describe what you need in at least 10 characters')
    .max(1000, 'Description must be 1000 characters or fewer'),
  locationName: z.string().min(2, 'Enter your location'),
  estimatedHours: z
    .number({ invalid_type_error: 'Select estimated hours' })
    .min(0.5)
    .max(72),
});

export const providerProfileSchema = z.object({
  displayName: z
    .string()
    .min(2, 'Name must be at least 2 characters')
    .max(60, 'Name must be 60 characters or fewer'),
  email: emailSchema,
  whatsappNumber: e164PhoneSchema,
  bio: z.string().max(500, 'Bio must be 500 characters or fewer'),
  skills: z
    .array(z.string())
    .min(1, 'Select at least one skill')
    .max(10, 'Select up to 10 skills'),
  locationName: z.string().min(2, 'Enter your location'),
});

export const contactInfoSchema = z.object({
  requesterWhatsapp: e164PhoneSchema,
  requesterEmail: emailSchema.optional().or(z.literal('')),
});

export const loginSchema = z.object({
  email: emailSchema,
  password: z.string().min(6, 'Password must be at least 6 characters'),

export const registerAccountSchema = z
```

## Step 9 — Build auth store and useAuth hook

**What to do:**
Create the Zustand auth store and the `useAuth` hook that wraps Firebase Auth state. The store holds the current user, loading state, and error state. The hook subscribes to `onAuthStateChanged` so the UI always reflects the true auth state. This is used by `ProtectedRoute` (Step 7) and `Navbar` (Step 8).

**Design decision:** The store is initialized in `authStore.ts` using Zustand's `create`. The `useAuth` hook calls `onAuthStateChanged` inside a `useEffect` (with the unsubscribe function as cleanup) — this is the correct pattern for Firebase Auth, not a data-fetching useEffect, so it does not violate AGENTS.md Section 5.2. The hook is the only place `onAuthStateChanged` is called — never in a component directly.

**Files to create:**
| File | Description |
|------|-------------|
| `src/store/authStore.ts` | Zustand store with state: `user: User \| null`, `loading: boolean`, `error: string \| null`. Actions: `setUser`, `setLoading`, `setError`, `clearError`. Exported as `useAuthStore` via `create`. No Firebase calls inside the store — the store is pure state. |
| `src/hooks/useAuth.ts` | Custom hook that calls `onAuthStateChanged(auth, ...)` in a `useEffect` (dependency: `[]` with comment explaining it runs once), updates `authStore` via `setUser`/`setLoading`. Exposes: `user`, `loading`, `isAuthenticated` (bool), `signOut` (calls `firebaseSignOut(auth)` and clears store). |

**src/store/authStore.ts content:**
